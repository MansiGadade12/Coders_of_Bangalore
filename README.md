# Coders_of_Bangalore

# Project Overview :

Coders of Bangalore is a Python-based data analysis project that processes unstructured social media profile data and converts it into structured information.
The project focuses on extracting profile details, cleaning the data, and analyzing different attributes such as posts, followers, following, bio, and profile categories.

# Objective :

- Read and process data from a text file.
- Split unstructured data into individual profiles.
- Extract useful information from each profile.
- Clean numerical values such as posts and followers.
- Store the processed information using Python data structures.
- Find profiles with the maximum number of posts, followers, and following.
- Identify the number of unique profile categories.

  # Technologies Used :

- Python
- File Handling
- Lists
- Dictionaries
- Sets
- Loops
- Functions
- String Manipulation

 # Key Analysis :

The project performs the following analysis:

1. Identifies the profile with the maximum followers.
2. Identifies the profile with the maximum posts.
3. Identifies the profile that follows the maximum number of people.
4. Finds the unique profile categories.
5. Processes and cleans profile information from raw text data.

Through this project, I learned how to work with unstructured data, perform data cleaning, use Python data structures, write reusable functions, 
and extract meaningful information from raw data.
